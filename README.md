# 보글사다리 MHS 무가중 V1

검증한 **Markov + HMM + Shape AI 포함판**을 Android 앱으로 구현한 버전입니다.

## 분석 규칙
- 최신 30회 Rolling 고정
- 좌/우 · 3/4줄 · 홀/짝 3개 차원을 각각 독립 분석
- Markov / 2-state HMM / Shape AI가 각각 **동등 1표**
- 엔진 간 학습 가중치 없음
- Shape AI 내부 3칸 / 4칸 / 5칸도 동일 비중
- Shape 완전일치 / 1칸 차이 유사일치도 모두 1건 = 1표
- 최고 1픽은 매회 1개 표시 (PASS 없음)
- 70% 이상은 "강신호"로만 표시하며, 70% 미만도 최고 1픽은 유지
- 내부 검증은 앞 15회 학습 후 뒤 15회를 미래값 없이 순차 재현

## 기능
- BEPICK 공개 JSON API 최신 결과 자동수집
- 3분 카운트다운
- 백그라운드 자동추첨 ON/OFF
- 이전 픽 자동채점 / 실전 승률 / 가상 수익
- 최근 30회 표시
- JSON 백업/복원
- 실전성적 초기화 / 전체 초기화

패키지: `com.bubbleladder.mhsunweightedv1`
